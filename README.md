# Programacion 1

Este repositorio contiene los programas y ejercicios
desarrollados durante la materia de Programacion 1.

## Progrmas incluidos

### Juego de luces
Juego para una persona con tablero de 10 luces en el cual
tienes que conseguir apagar todas las luces para ganar

### Blackjack
Juego de una persona donde se reparten 2 cartas al azar y tienes que conseguir una puntuacion de cartas
de 21 puntos para ganar y si pasas esa cantidad o el dealer tiene mas pierdes

### Cifrado CESAR
Programa que cifra una palabra o palabras de acuerdo al desplazamiento
que tu le asignes.

### Validador de contraseñas
Este programa valida si la contraseña dada por el usuario es segura o insegura dependiendo
de los criterios asignados en el programa
